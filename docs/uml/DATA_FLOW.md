## Data Contracts

### Media Input

Contains a supported video reference and metadata needed for processing. Raw media should not be copied into source control.

### Modality Representation

Versioned numerical representation generated by the visual or audio preprocessing/encoder pipeline.

### Prediction Record

Should associate the prediction with model version, preprocessing/configuration version, sample identifier, modality mode, score, and evaluation context where applicable.

### Experiment Record

Should record dataset/split version, configuration, seed, model identifier, metrics, and status.

## Leakage Controls

The data flow explicitly separates:

- raw dataset;
- audited metadata;
- split definition;
- training transformations;
- validation/test evaluation.

No test-derived preprocessing statistics or labels may be used to modify training decisions after the test set is frozen.
